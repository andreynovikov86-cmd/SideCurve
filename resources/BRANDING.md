# Andrey Novikov AN branding

The user selected the AN monogram and the light upright credit
`by Andrey Novikov` for SideCurve. Manufacturer/author metadata remains
Andrey Novikov. This replaces the previous Plugin King presentation.

`AndreyNovikov-AN.svg` is the vector master for the approved maker mark.
`src/Branding.h` and JSFX's `brand_mark` use the same outlines, simplified at
sub-pixel UI scale and checked for area preservation. Native filling uses
even-odd paths; JSFX uses a cached supersampled triangulation.

The author credit uses ordinary upright Arial Regular, not the heavy condensed
display wordmark. No font file is redistributed. The maker mark is independent
of installed fonts. The separate logo kit retains the full personal wordmark
for larger branding uses; that heavy wordmark is not used for the small credit.

Current host screenshots are in docs/SideCurve.png; the approved design study
is in docs/branding/AndreyNovikov-approved.png. Both formats were inspected in
an isolated REAPER configuration on 26 October 2026.
